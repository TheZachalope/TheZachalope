Going Forward with Website Coding

Zachalope June 12, 2025

So going forward with the website, I'm not using any builder. I took the template I had make using Silex and am in the process of renaming and decluttering the CSS coding to better fit my needs. Now, I'm using VSCode to edit my coding and a live-server plugin to see changes before pushing it to the site via git with Github Pages. It's nice, really. I just finished updating all the CSS for my blog entries, so if I want to change the look of them, I'll only need to update one area. Previously it would have been one at a time.

I still have a ton to learn about CSS and HTML, so I'll continue The Odin Project on my laptop and Mimo on my phone occasionally, but I'll probably be slower paced at it now that I've got this setup in such a way I can easily update the blog. Likely, I'll spend more lunches reading now.
